# GRC Skills

Skills for Governance, Risk, and Compliance (GRC) work covering ISMS, AIMS, and the
Compliance Management System (CMS).

## grc-office

Guidance for GRC office responsibilities: planning, monitoring, improving, and
controlling compliance, governance, and risk programs across ISMS, AIMS, CMS, and GRC.

```bash
npx skills add sakibntanmoy006/grc-skills@grc-office
```

## cms

Guidance for implementing, automating, and operating a certifiable Compliance
Management System based on ISO 37301, with supporting integrity standards (ISO 37001,
37002, 37003), a 15-day PDCA launch roadmap, I-BOS automation modules, and dashboard
KPIs/KRIs.

```bash
npx skills add sakibntanmoy006/grc-skills@cms
```

## compliance-catalog

Catalog of 584 enterprise compliance requirements across 80 domains and 11 categories,
with an index of requirement names, domains, categories, applicability, and process
owners. Use it to populate obligation registers, build risk-control matrices, and plan
monitoring and audits.

```bash
npx skills add sakibntanmoy006/grc-skills@compliance-catalog
```
